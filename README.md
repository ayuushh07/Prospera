# Prospera — Paper Trading Simulator

A portfolio demo for a paper trading app. This version runs fully in the browser using JavaScript and localStorage so it can be deployed instantly.

## What it demonstrates
- Stock search UI
- Watchlist management
- Buy/sell form validation
- Portfolio holdings
- Transaction history
- SVG chart rendering
- Local persistence through localStorage

## Run locally
Open `index.html` in your browser.
